# -图片二维码双向转换系统-
这是一个基于 Python 的 图片二维码双向转换系统 ，通过类Base64 编码将图片数据嵌入二维码，实现"图片→二维码→图片"的完整传输链路。项目分为生成端和识别端两个独立程序

## 一、生成端 base64(QR传图__生成端)v6.0.py
### 核心功能：图片 → 二维码
┌──────────────────────────────────────────────────────────────┐
│                       QR传图 - 生成端                          │
├──────────────────────────────────────────────────────────────┤
│  [选择图片]  [确定选取]                                        │
├──────────────────────────────────────────────────────────────┤
│  [压缩尺寸] ○8×8 ○16×16 ○24×24 ○32×32 ○40×40 ○48×48 ...     │
│  [压缩算法] ○BOX ○LANCZOS ○BILINEAR ○BICUBIC ○NEAREST       │
├──────────────────────────────────────────────────────────────┤
│  ┌──────────┐  ┌──────────┐  ┌─────────────────────────────┐ │
│  │ 原图预览  │  │压缩后预览 │  │  基础信息 (2×2网格)         │ │
│  │          │  │          │  │  未压缩 │ 压缩后              │ │
│  │          │  │          │  │  Base64 │ QR码                │ │
│  └──────────┘  └──────────┘  ├─────────────────────────────┤ │
│                              │  [比例修正]                  │ │
│                              │  生成的二维码                │ │
│                              └─────────────────────────────┘ │
├──────────────────────────────────────────────────────────────┤
│  [保存QR码]  [重置程序]                                        │
└──────────────────────────────────────────────────────────────┘
备注：本系统所转化的Base64编码非原版Base64,为了使转化的图片保留原图比例，在原版base64基础上在末尾加上了图片比例识别码（base64数据|RATIO:长:宽）
## 关键技术
- 压缩算法 ： Image.Resampling.BOX （区域平均采样）等
- 比例修正格式 ： base64数据|RATIO:长:宽
- 数据编码 ：JPEG → BytesIO → Base64

## 二、识别端 base64(QR传图__识别端)v6.0.py
### 核心功能：二维码 → 图片
┌──────────────────────────────────────────────────────────────┐
│                       QR传图 - 识别端                          │
├──────────────────────────────────────────────────────────────┤
│                       [上传QR码]                               │
├──────────────────────────────────────────────────────────────┤
│  ┌──────────┐  ┌──────────────┐  ┌─────────────────────────┐ │
│  │ QR码预览  │  │ 识别结果      │  │ 结果优化                 │ │
│  │          │  │ 宽高比例: 4:3 │  │ 放大倍数: [2]            │ │
│  │          │  │              │  │ ☑ Wiener滤波            │ │
│  │          │  │  (按比例还原) │  │ [执行优化]              │ │
│  │          │  │              │  │                         │ │
│  │          │  │              │  │  (优化后图片)           │ │
│  └──────────┘  └──────────────┘  └─────────────────────────┘ │
├──────────────────────────────────────────────────────────────┤
│  [复制源码] [保存图片] [保存优化图] [重置程序]                  │
└──────────────────────────────────────────────────────────────┘
备注：使用多种图像优化算法，可大幅度提高识别后图片的质量，同时增加可自选参数，自由调节图像质量，优化流程如下：
                                    原图（按比例还原）
                                        ↓
                                    1. Wiener滤波（可选）    ← 去模糊
                                        ↓
                                    2. Lanczos插值（1-8倍）  ← 高质量放大
                                        ↓
                                    3. 双边滤波              ← 去噪保边
                                        ↓
                                    4. USM锐化（30%强度）    ← 增强细节
                                        ↓
                                    优化后图片

## 三、数据传输协议
### 完整数据流
生成端                                    识别端
─────                                    ─────
原图 (如 1920×1080)                        
    ↓                              
压缩 (如 16×16, BOX算法)                 
    ↓                                   
JPEG编码 → Base64                         
    ↓                                     
附加比例信息                              
"base64数据|RATIO:16:9"                   
    ↓                                     
生成二维码  ────────扫码──────►           识别QR码
                                           ↓
                                       解析数据
                                           ↓
                                       分离 base64 与 RATIO
                                           ↓
                                       Base64 → 图片 (16×16)
                                           ↓
                                       按比例还原 (16:9)
                                           ↓
                                       显示/优化/保存

## 四、技术栈
                          类别             库/技术
                          GUI框架          tkinter
                          图片处理         Pillow (PIL)
                          二维码生成       qrcode
                          二维码识别       pyzbar / opencv-python
                          图像优化         OpenCV (双边滤波、Wiener、USM锐化)
                          数据编码         base64 (标准库)
                          数学计算         math (gcd 最大公约数)

## 五、应用场景
1. 图片离线传输 ：通过二维码扫码传输小图片，无需网络
2. 图片压缩演示 ：直观展示不同压缩算法的效果差异
3. 图像处理学习 ：演示Base64编码、二维码、图像优化算法
4. 跨设备传输 ：生成端在PC，识别端可在手机（需移植）


这是一个功能完整、结构清晰的图像二维码转换工具，覆盖了从图片压缩、编码、传输到识别、还原、优化的完整链路。
